# น้องมูฟ ซีซั่น 2 — "หาแฟนใหม่ใน 30 วัน" 💘

## คอนเซปต์
- ต่อจากซีซั่น 1 ตอนจบ (Day 30: มูฟออน 100% → หนุ่มฟิตเนสทักมา)
- ตัวนับมุมจอใหม่: **"เหลือ X วัน · ใจเต้น X%"** (สีชมพู แทนสีเขียว/แดงของมูฟออน)
- โทนสีหลักเปลี่ยนเป็น ชมพู-ม่วง-ส้มพระอาทิตย์ตก ให้รู้สึกเป็นซีซั่นใหม่
- น้องมูฟผมทรงเห็ดเริ่มยาวขึ้น (เวลาผ่านไปจริง)
- **คนดูมีส่วนร่วม:** ทุกวันอาทิตย์ (D7, D14, D21) ให้โหวตในคอมเมนต์ว่าจะเลือกใคร / ทำอะไรต่อ

## ตัวละคร
| ตัวละคร | บทบาท | ลุค |
|---|---|---|
| น้องมูฟ | ตัวเอก | ฮู้ดชมพู ผมทรงเห็ด |
| ภูมิ (หนุ่มฟิตเนส) | ตัวเลือก 1 — อบอุ่น จริงใจ แต่คนจีบเยอะ | ฮู้ดน้ำเงิน ผมตั้ง |

| บอส (เพื่อนสนิท) | ตัวเลือก 3 — อยู่ข้างๆ มาตลอด แอบชอบ | ฮู้ดเทา |
| แฟนเก่า | ตัวป่วน กลับมาขอคืนดี | ฮู้ดม่วงเทา |
| พี่ฝน / มายด์ / แม่ | ตัวช่วย (เดิมจากซีซั่น 1) | เดิม |
