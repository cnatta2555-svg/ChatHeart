```
[มือถือ หน้ารายชื่อ "ที่รัก ❤️"]

[นิ้วจ่อปุ่มลบ สั่น]
กดลบ... ยืนยัน... ลบแล้ว!
[ตัวละครยิ้มภูมิใจ]
ง่ายจะตาย มูฟออนแล้วค่า
[หน้าแป้นกด ตัวเลขพิมพ์เองทีละตัว]
แต่ปัญหาคือ... ฉันจำเบอร์เขาได้ทุกตัว

[เอามือถือไปซ่อนในตู้เย็น]
```

## Day 3 — กล่องของขวัญ (-25% → -30%)
```
[ตัวละครยกกล่องใหญ่]
วันที่สาม... เก็บของขวัญจากเขาใส่กล่อง เอาไปทิ้ง
[หยิบตุ๊กตาหมี]
ตุ๊กตาหมี... ตัวนี้ได้ตอนวาเลนไทน์
[หยิบตั๋วหนัง]
ตั๋วหนังเรื่องแรกที่ดูด้วยกัน...
[หยิบเสื้อฮู้ด ดม]
เสื้อฮู้ดของเขา... ยังมีกลิ่นอยู่เลย
[กอดทุกอย่างร้องไห้ ข้างถังขยะ]
ยืนหน้าถังขยะมาชั่วโมงนึงแล้ว... ทิ้งไม่ลง
[แอบเอากล่องไปซุกใต้เตียง]
เอาไว้ใต้เตียงก่อนละกัน ไม่ได้เก็บนะ แค่ฝากไว้
จบวันที่สาม มูฟออนติดลบสามสิบเปอร์เซ็นต์
วันที่สี่เริ่มแล้ว... ตอนหน้า เพลงมันเล่นงานฉัน
```

## Day 4 — เพลงอกหัก (-30% → -40%)
```
[ใส่หูฟัง เดินออกจากบ้าน]
วันที่สี่... วันนี้จะฟังแต่เพลงสนุกๆ
[กดสุ่มเพลง หน้าจอขึ้นเพลงเศร้า]
กดสุ่มเพลง... ได้เพลงอกหัก
กดข้าม... อกหักอีก
กดข้าม... เพลงที่เราเคยร้องคู่กัน!
[ขึ้นแท็กซี่ วิทยุก็เปิดเพลงเศร้า]
หนีขึ้นแท็กซี่... ลุงเปิดเพลงเดียวกันเป๊ะ
[ร้องไห้ ลุงคนขับร้องไห้ด้วย]
สุดท้ายนั่งร้องไห้กับลุงทั้งคัน
จบวันที่สี่ มูฟออนติดลบสี่สิบเปอร์เซ็นต์
วันที่ห้าเริ่มแล้ว... ตอนหน้า หมูกระทะช่วยได้ไหม?
```

## Day 5 — หมูกระทะ (-40% → -30%)
```
[เพื่อนสามคนลากตัวละครออกจากห้อง]

[ปิ้งหมู ตัวละครยิ้มได้]
หมูก็อร่อย เพื่อนก็ตลก... ลืมเขาไปแล้วจริงๆ
[ตัวนับขึ้น -30%]
[พนักงานเดินมา]
จนพนักงานถามว่า...

[ตัวละครหน้าค้าง ตะเกียบหล่น]
...
[เพื่อนยัดหมูใส่ปากตัวละคร]

จบวันที่ห้า มูฟออนติดลบสามสิบเปอร์เซ็นต์ ยังดีขึ้นนิดนึง
วันที่หกเริ่มแล้ว... ตอนหน้า ห้ามแตะมือถือตอนเมา
```
