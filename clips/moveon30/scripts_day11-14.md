## Day 11 — ลงสตอรี่ให้เขาเห็น (0% → -5%)
เพิ่มใน style: _ตอนกดรีเฟรชให้ลนลานขึ้นเรื่อยๆ ตอนท้ายให้ประชดตัวเองแบบเหนื่อยๆ_
```
[แต่งหน้าจัดเต็ม ถ่ายเซลฟี่ร้อยรูป]
วันที่สิบเอ็ด... แต่งหน้าจัดเต็ม ถ่ายเซลฟี่ไปร้อยรูป
[เลือกรูป ใส่แคปชั่น]
ลงสตอรี่ แคปชั่นว่า... ชีวิตดีมาก ไม่ได้คิดถึงใครเลย
[หน้ารายชื่อคนดู ไม่มีเขา]
ห้านาทีผ่านไป... เขายังไม่ดู
[กดรีเฟรชรัวๆ]
รีเฟรช... รีเฟรช... รีเฟรชไปห้าสิบรอบ
[ตัวนับคนดู มีแต่แม่กับเพื่อน]
คนดูมีแค่แม่... กับเพื่อนสองคน
[นั่งเหม่อ]
ลงสตอรี่ให้คนที่ไม่ดู... เหมือนร้องเพลงให้ห้องว่าง
จบวันที่สิบเอ็ด มูฟออนติดลบห้าเปอร์เซ็นต์
วันที่สิบสองเริ่มแล้ว... ตอนหน้า แม่โทรมา
```

## Day 12 — แม่โทรมา (-5% → 5%)
เพิ่มใน style: _เสียงแม่ให้อ่อนโยน อบอุ่นแบบแม่ไทย ตอนพูดกับแม่ให้เสียงสั่นแล้วร้องไห้ ตอนท้ายให้ซึ้งปนยิ้ม_
```
[มือถือสั่น หน้าจอขึ้น "แม่ ❤️"]
วันที่สิบสอง... แม่โทรมา
[เสียงแม่]
ลูก... แฟนสบายดีไหม ไม่เห็นพามาบ้านเลย
[ตัวละครหน้าค้าง]
...
[น้ำตาไหล]
เลิกกันแล้วแม่... สามเดือนแล้ว
[แม่เงียบ แล้วพูดเบาๆ]
งั้นกลับบ้านมากินข้าวนะลูก แม่ทำต้มยำไว้ให้
[ตัวละครนั่งกินข้าวกับแม่ แม่ตักกับข้าวให้]
แม่ไม่ถามอะไรเลย... แค่ตักกับข้าวให้ไม่หยุด
[ยิ้มทั้งน้ำตา]
เลิกกับแฟนได้... แต่บ้านยังรอเราเสมอ
จบวันที่สิบสอง มูฟออน ห้าเปอร์เซ็นต์ บวกแล้ว!
วันที่สิบสามเริ่มแล้ว... ตอนหน้า เขาไลก์สตอรี่ฉัน!
```

## Day 13 — เขาไลก์สตอรี่ (5% → -15%)
เพิ่มใน style: _ตอนเห็นแจ้งเตือนให้ตกใจสุดตัว ตอนคิดมากให้พูดรัวเร็วเหมือนสมองทำงานหนัก_
```
[ลงสตอรี่รูปวิ่งที่ฟิตเนส]
วันที่สิบสาม... ลงสตอรี่รูปไปฟิตเนส ไม่ได้หวังอะไรเลย
[แจ้งเตือนเด้ง]
แล้วแจ้งเตือนก็เด้ง...
เขา... ไลก์สตอรี่ฉัน!
[หัวใจเต้นแรง ตัวลอย]
หัวใจเต้นแรงจนได้ยินเสียง
[สมองหมุน คำถามลอยเต็มหัว]
หมายความว่าไง? คิดถึงเหรอ? อยากกลับมาเหรอ?
หรือนิ้วลั่น... เหมือนฉันวันแรก
[นอนกลิ้งไปมา ไม่หลับ]
คิดจนตีสาม... ทั้งที่เขาคงหลับไปตั้งแต่สี่ทุ่ม
จบวันที่สิบสาม มูฟออนตกลงไป ติดลบสิบห้าเปอร์เซ็นต์
วันที่สิบสี่เริ่มแล้ว... ตอนหน้า สรุปสัปดาห์ที่สอง
```

## Day 14 — สรุปสัปดาห์ที่สอง (-15% → 10%)
เพิ่มใน style: _ช่วงท้ายให้มั่นใจ อบอุ่น คุยกับคนดูตรงๆ_
```
[กราฟมูฟออนสัปดาห์ที่สอง]
วันที่สิบสี่... ครบสองสัปดาห์แล้ว
[สไลด์ภาพทีละวัน]
ได้ผมทรงเห็ด ได้กล้ามแขนนิดนึง
กดอันฟอลโลว์เขาได้ แล้วก็ได้กินข้าวฝีมือแม่
[รูปแจ้งเตือนไลก์]
ไลก์เดียวของเขา ทำใจสั่นทั้งคืน
[ยิ้มมั่นใจ]
แต่รู้อะไรไหม... ฉันไม่ได้ตอบอะไรกลับไปเลย
[ตัวนับวิ่งขึ้นเป็น 10%]
มูฟออน สิบเปอร์เซ็นต์... ครึ่งทางแล้ว
[หันมาพูดกับกล้อง]
ถ้าเป็นคุณ แฟนเก่ามาไลก์สตอรี่ จะตอบไหม? คอมเมนต์บอกหน่อย
สัปดาห์ที่สามเริ่มแล้ว... ตอนหน้า ไปทะเลคนเดียว
```
