## Day 22 — เขาทักมา (55% → 30%)
เพิ่มใน style: _ช่วงแรกสบายๆ มีความสุข พอเห็นข้อความให้ช็อกจนเสียงหาย แล้วค่อยๆ สับสน_
```
[นั่งกินข้าวกับเพื่อน หัวเราะ]
วันที่ยี่สิบสอง... ชีวิตกำลังดีเลย กินข้าวกับเพื่อน หัวเราะทั้งวัน
[มือถือสั่น ข้อความเด้ง]
แล้วมือถือก็สั่น...
[ชื่อขึ้นจอ "ex.jaa_"]
ชื่อที่ไม่ได้เห็นมายี่สิบสองวัน...
[ข้อความ "สบายดีไหม"]
เขาทักมาว่า... สบายดีไหม
[ตัวละครค้าง ช้อนหล่น]
...
[ภาพความทรงจำวนกลับมา]
ทุกอย่างที่ทำมาสามสัปดาห์... เหมือนพังลงในสามคำ
[นั่งจ้องจอ ไม่กล้ากดเปิด]
ยังไม่ได้กดอ่าน... แต่อ่านซ้ำในหัวไปร้อยรอบแล้ว
จบวันที่ยี่สิบสอง มูฟออนตกลงไป เหลือสามสิบเปอร์เซ็นต์
วันที่ยี่สิบสามเริ่มแล้ว... ตอนหน้า จะตอบ หรือไม่ตอบ?
```

## Day 23 — ตอบหรือไม่ตอบ (30% → 35%)
เพิ่มใน style: _ตอนเถียงกับตัวเองให้สลับเสียงนางฟ้าใจดีกับนางมารกวนๆ ตอนท้ายให้จริงจัง ขอความเห็นคนดู_
```
[นั่งบนเตียง กอดมือถือ]
วันที่ยี่สิบสาม... ข้อความยังอยู่ ยังไม่ได้ตอบ
[นางฟ้าโผล่ไหล่ขวา]
นางฟ้าบอกว่า... ตอบไปสุภาพๆ ก็ได้ ไม่เสียหาย
[นางมารโผล่ไหล่ซ้าย]
นางมารบอกว่า... อ่านแล้วไม่ตอบ ให้เขารู้บ้างว่ามันเจ็บยังไง
[นางฟ้ากับนางมารทะเลาะกัน]
สองคนนี้เถียงกันทั้งคืน... ฉันนอนไม่หลับเลย
[เพื่อนส่งสติกเกอร์]
เพื่อนบอกว่า... อย่าตอบ!
แม่บอกว่า... ทำตามใจลูก
[หันมาพูดกับกล้อง]
ถ้าเป็นคุณ จะตอบไหม? คอมเมนต์ ตอบ หรือ ไม่ตอบ มาเลย
จบวันที่ยี่สิบสาม มูฟออน สามสิบห้าเปอร์เซ็นต์
วันที่ยี่สิบสี่เริ่มแล้ว... ตอนหน้า ฉันตัดสินใจแล้ว
```

## Day 24 — ตอบสั้นๆ แล้วปิดแชท (35% → 60%)
เพิ่มใน style: _ตอนพิมพ์ให้ลังเล ตอนกดส่งให้มั่นใจ ตอนท้ายให้ภูมิใจ โล่งใจ_
```
[นิ้วจ่อแป้นพิมพ์]
วันที่ยี่สิบสี่... ฉันตัดสินใจแล้ว
[พิมพ์ยาว แล้วลบ]
พิมพ์ไปยาวเหยียด... ลบ
พิมพ์ใหม่... ลบอีก
[พิมพ์คำเดียว]
สุดท้ายเหลือแค่... สบายดีจ้า
[กดส่ง]
ส่ง!
[เขาพิมพ์... อยู่]
เขาขึ้นว่ากำลังพิมพ์...
[ตัวละครกดปิดแชท ปิดเสียงแจ้งเตือน]
แต่ฉันกดปิดแชท... ไม่รออ่าน
[ยิ้มกว้าง แดดออก]
ไม่ได้โกรธ ไม่ได้รอ... แค่ไม่ต้องการคำตอบอะไรจากเขาอีกแล้ว
จบวันที่ยี่สิบสี่ มูฟออน หกสิบเปอร์เซ็นต์
วันที่ยี่สิบห้าเริ่มแล้ว... ตอนหน้า เจอเขาที่ห้าง!
```

## Day 25 — เจอเขาที่ห้าง (60% → 65%)
เพิ่มใน style: _ตอนเห็นเขาให้ตกใจกระซิบเสียงลน ตอนหลบหุ่นให้ฮา ตอนท้ายให้สงบ มั่นใจ_
```
[เดินห้างกับเพื่อน ถือถุงช้อปปิ้ง]
วันที่ยี่สิบห้า... เดินห้างกับเพื่อน ช้อปปิ้งสบายใจ
[เห็นเขาไกลๆ เดินกับคนใหม่]
แล้วก็เห็นเขา... เดินมากับคนใหม่
[รีบหลบหลังหุ่นโชว์เสื้อผ้า]
ร่างกายวิ่งไปหลบหลังหุ่นโชว์อัตโนมัติ
[พนักงานมองแปลกๆ]
พนักงานถามว่า... น้องจะลองชุดหุ่นตัวนี้ไหมคะ
[สูดหายใจ เดินออกมา]
แต่แล้วฉันก็คิดได้... ทำไมต้องหลบ ฉันไม่ได้ทำอะไรผิด
[เดินสวนกัน เขาทัก]
เดินสวนกันไป เขาทักว่า หวัดดี...
[ยิ้ม พยักหน้า เดินต่อ]
ฉันยิ้ม พยักหน้า แล้วเดินต่อ... ไม่หันกลับไปมองเลย
จบวันที่ยี่สิบห้า มูฟออน หกสิบห้าเปอร์เซ็นต์
วันที่ยี่สิบหกเริ่มแล้ว... ตอนหน้า ทำไมรู้สึกเฉยๆ
```
