## Day 15 — ไปทะเลคนเดียว (10% → 15%)
เพิ่มใน style: _ช่วงแรกสดใสตื่นเต้น ช่วงเหงาให้เสียงเบาลง ตอนท้ายให้สงบและอบอุ่น_
```
[รถทัวร์ ใส่หมวกปีกกว้าง]
วันที่สิบห้า... นั่งรถทัวร์ไปทะเลคนเดียว
[ชายหาด คู่รักเดินจูงมือเต็มไปหมด]
ถึงปุ๊บ... เจอแต่คู่รักจูงมือกันทั้งหาด
[ยืนถือไม้เซลฟี่คนเดียว]
ถ่ายรูปคู่ไม่ได้... เลยถ่ายคู่กับปูแทน
[ปูหนีบนิ้ว]
ปูหนีบนิ้ว... ขนาดปูยังไม่อยากอยู่กับฉัน
[นั่งดูพระอาทิตย์ตก]
แต่พอพระอาทิตย์ตก... ฉันนั่งดูคนเดียว แล้วรู้สึกว่ามันก็ไม่ได้แย่นี่นา
จบวันที่สิบห้า มูฟออน สิบห้าเปอร์เซ็นต์
วันที่สิบหกเริ่มแล้ว... ตอนหน้า ทำอาหารกินเองครั้งแรก
```

## Day 16 — ทำอาหารกินเองครั้งแรก (15% → 20%)
เพิ่มใน style: _ตอนครัวไฟลุกให้ตกใจโวยวาย ตอนกินให้ภูมิใจแบบฮาๆ_
```
[ครัว เปิดคลิปสอนทำอาหาร]
วันที่สิบหก... จะเลิกสั่งเดลิเวอรี่ ทำอาหารกินเอง
[ทอดไข่ น้ำมันกระเด็น]
เมนูแรก ไข่เจียว... น้ำมันกระเด็นเหมือนโดนยิง
[ควันขึ้น สัญญาณเตือนไฟดัง]
ไข่ไหม้... สัญญาณเตือนไฟดังทั้งตึก
[ยามขึ้นมาเคาะประตู]
ยามขึ้นมาถามว่า... น้องเผาอะไรอยู่ครับ
[นั่งกินไข่ไหม้ ยิ้มภูมิใจ]
ไหม้ไปครึ่งนึง... แต่เป็นไข่เจียวที่อร่อยที่สุดในชีวิต เพราะทำเอง
จบวันที่สิบหก มูฟออน ยี่สิบเปอร์เซ็นต์
วันที่สิบเจ็ดเริ่มแล้ว... ตอนหน้า หนุ่มฟิตเนสยิ้มให้
```

## Day 17 — หนุ่มฟิตเนสยิ้มให้ (20% → 30%)
เพิ่มใน style: _ตอนเขายิ้มให้ให้เขินสุดๆ พูดรัวเร็ว ตอนท้ายให้ฮาแบบหน้าแตก_
```
[ฟิตเนส วิ่งลู่วิ่ง]
วันที่สิบเจ็ด... ไปฟิตเนสเหมือนเดิม
[หนุ่มลู่วิ่งข้างๆ หันมายิ้ม]
แล้วหนุ่มลู่วิ่งข้างๆ... หันมายิ้มให้!
[หัวใจเด้ง ตัวลอย]
ใจเต้นแรง... แบบที่ไม่ได้เต้นมานานแล้ว
[ตัวละครยิ้มกลับ ลู่วิ่งเร็วขึ้น]
ยิ้มกลับไปอย่างมั่นใจ... แล้วก็...
[ตกจากลู่วิ่ง]
ตกลู่วิ่ง!
[หนุ่มเข้ามาช่วย]
เขาเข้ามาช่วยพยุง... หน้าแตกแต่ได้จับมือ
จบวันที่สิบเจ็ด มูฟออน สามสิบเปอร์เซ็นต์
วันที่สิบแปดเริ่มแล้ว... ตอนหน้า โหลดแอปหาคู่
```

## Day 18 — โหลดแอปหาคู่ (30% → 25%)
เพิ่มใน style: _ตอนไล่ปัดโปรไฟล์ให้จังหวะเร็ว ตอนเจอคนแปลกๆ ให้ตกใจระคนขำ_
```
[โหลดแอป ตั้งโปรไฟล์]
วันที่สิบแปด... เพื่อนยุให้โหลดแอปหาคู่
[ปัดซ้ายปัดขวา]
ปัดซ้าย... ปัดซ้าย... ปัดขวา!
[แมตช์! แชทเด้ง]
แมตช์แล้ว! เขาทักมาเลย
[ข้อความประหลาด]
ประโยคแรก... น้องสนใจธุรกิจเครือข่ายไหมครับ
[แมตช์ที่สอง รูปไม่ตรงปก]
คนที่สอง... รูปในแอปหล่อมาก ตัวจริงคือรูปจากเมื่อสิบปีก่อน
[ลบแอป]
สรุป... ลบแอปทิ้ง ขอใช้ชีวิตแบบออฟไลน์ไปก่อน
จบวันที่สิบแปด มูฟออน ยี่สิบห้าเปอร์เซ็นต์
วันที่สิบเก้าเริ่มแล้ว... ตอนหน้า เพื่อนเล่าความลับของเขา
```

## Day 19 — เพื่อนเล่าความลับ (25% → 40%)
เพิ่มใน style: _ตอนได้ยินความลับให้ช็อกและโกรธ ตอนท้ายให้โล่งใจ หัวเราะออกมาได้_
```
[คาเฟ่ เพื่อนนั่งตรงข้าม หน้าลังเล]
วันที่สิบเก้า... เพื่อนนัดกินกาแฟ บอกว่ามีเรื่องต้องเล่า
[เพื่อนกระซิบ]
แก... รู้ไหม คนใหม่ของเขาน่ะ
คุยกันตั้งแต่ตอนที่เขายังคบกับแกอยู่
[ตัวละครหน้าค้าง แก้วกาแฟสั่น]
...
[ไฟลุก โกรธ]
ร้องไห้มาสองอาทิตย์... ให้คนแบบนี้เหรอ!
[เมฆดำหายไป แดดออก]
แต่แปลกนะ... พอรู้ความจริง ใจมันเบาขึ้นเยอะเลย
ไม่ต้องสงสัยแล้วว่าเราทำอะไรผิด
จบวันที่สิบเก้า มูฟออน สี่สิบเปอร์เซ็นต์
วันที่ยี่สิบเริ่มแล้ว... ตอนหน้า ลบรูปคู่ทั้งหมด
```

## Day 20 — ลบรูปคู่ทั้งหมด (40% → 50%)
เพิ่มใน style: _ช่วงไล่ดูรูปให้คิดถึงนิดๆ ตอนกดลบให้เด็ดขาด ตอนท้ายให้ภูมิใจ_
```
[แกลเลอรี่ รูปคู่เต็มจอ]
วันที่ยี่สิบ... เปิดแกลเลอรี่ รูปคู่สองพันสามร้อยรูป
[เลื่อนดูรูปเก่า]
รูปไปทะเล... รูปวันเกิด... รูปหมูกระทะร้านเดิม
[กดเลือกทั้งหมด นิ้วจ่อปุ่มลบ]
กดเลือกทั้งหมด...
[กดลบ รูปหายเป็นผุยผง]
ลบ!
[ระบบถามว่าจะลบจากถังขยะด้วยไหม]
มือถือถามว่า ลบถาวรไหม... ลบ!
[พื้นที่ว่างเพิ่ม]
พื้นที่มือถือว่างเพิ่มสิบกิกะ... หัวใจก็โล่งขึ้นอีกเยอะ
จบวันที่ยี่สิบ มูฟออน ห้าสิบเปอร์เซ็นต์ ครึ่งหนึ่งแล้ว!
วันที่ยี่สิบเอ็ดเริ่มแล้ว... ตอนหน้า สรุปสัปดาห์ที่สาม
```

## Day 21 — สรุปสัปดาห์ที่สาม (50% → 55%)
เพิ่มใน style: _ช่วงท้ายให้อบอุ่น มั่นใจ คุยกับคนดูตรงๆ_
```
[กราฟมูฟออนสัปดาห์ที่สาม พุ่งขึ้น]
วันที่ยี่สิบเอ็ด... ครบสามสัปดาห์แล้ว
[สไลด์ภาพทีละวัน]
ไปทะเลคนเดียว โดนปูหนีบ
ทำไข่เจียวจนยามขึ้นมาเคาะประตู
ตกลู่วิ่งต่อหน้าหนุ่มหล่อ แล้วก็เจอคนชวนขายตรง
[เพื่อนกอด]
รู้ความจริงที่เจ็บ... แต่ทำให้ใจเป็นอิสระ
[ตัวนับวิ่งขึ้นเป็น 55%]
มูฟออน ห้าสิบห้าเปอร์เซ็นต์... สัปดาห์นี้ดีที่สุดเลย
[หันมาพูดกับกล้อง]
ใครเคยรู้ความจริงแล้วใจเบาขึ้นบ้าง คอมเมนต์เล่าให้ฟังหน่อย
สัปดาห์สุดท้ายเริ่มแล้ว... ตอนหน้า เขาทักมา
```
