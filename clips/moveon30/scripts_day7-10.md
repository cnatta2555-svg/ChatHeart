## Day 7 — สรุปสัปดาห์แรก (-25% → -20%)
เพิ่มใน style: _ช่วงท้ายให้จริงใจขึ้น อบอุ่น เหมือนคุยกับคนดูตรงๆ_
```
[นั่งริมหน้าต่าง กราฟมูฟออนขึ้นลง]
วันที่เจ็ด... ครบหนึ่งสัปดาห์แล้ว
[สไลด์ภาพทีละวัน]
ส่องไอจี กดไลก์ จำเบอร์ได้ ทิ้งของขวัญไม่ลง
ร้องไห้กับลุงแท็กซี่ แล้วก็ทำมือถือพัง
[หัวเราะทั้งน้ำตา]
ฟังดูแย่ใช่ไหม... แต่รู้อะไรไหม
ฉันยังไม่ได้ทักเขาเลยสักครั้ง
[ตัวนับขึ้นเป็น -20%]
มูฟออนติดลบยี่สิบเปอร์เซ็นต์... แต่ไม่ได้ยอมแพ้
[หันมาพูดกับกล้อง]
ใครกำลังมูฟออนอยู่เหมือนกัน คอมเมนต์บอกหน่อย ว่าตอนนี้กี่เปอร์เซ็นต์แล้ว
สัปดาห์ที่สองเริ่มแล้ว... ตอนหน้า ตัดผมใหม่ ชีวิตใหม่
```

## Day 8 — ตัดผมใหม่ (-20% → -15%)
เพิ่มใน style: _ตอนเห็นผมในกระจกให้กรี๊ด แล้วค่อยๆ ยอมรับแบบงงๆ_
```
[หน้าร้านทำผม]
วันที่แปด... เขาว่ากันว่า อกหักต้องตัดผม
[นั่งเก้าอี้ ยื่นรูปให้ช่าง]
ขอทรงนี้ค่ะพี่ สวยๆ เปรี้ยวๆ ลืมแฟนเก่า
[ช่างตัดเร็วมาก ผมปลิว]
ช่างตัดไปฮัมเพลงไป... เพลงอกหักอีกแล้ว
[หมุนเก้าอี้ เห็นกระจก ผมทรงเห็ด]
อ๊ากกก! ทำไมเป็นทรงเห็ด!
[ยืนส่องกระจก หันซ้ายหันขวา]
แต่ดูไปดูมา... ก็แปลกใหม่ดี เหมือนคนใหม่จริงๆ
[เพื่อนถ่ายรูป หัวเราะ]
เพื่อนบอกน่ารัก... หลังจากหัวเราะไปสิบนาที
จบวันที่แปด มูฟออนติดลบสิบห้าเปอร์เซ็นต์
วันที่เก้าเริ่มแล้ว... ตอนหน้า สมัครฟิตเนส
```

## Day 9 — สมัครฟิตเนส (-15% → -10%)
เพิ่มใน style: _ตอนออกกำลังให้หอบเหนื่อย ตอนปวดตัวให้ครวญครางแบบฮาๆ_
```
[หน้าฟิตเนส ตัวละครใส่ชุดกีฬา]
วันที่เก้า... สมัครฟิตเนส จะกลับไปให้เขาเสียดาย
[ยกดัมเบลเล็กๆ แขนสั่น]
ยกดัมเบลหนึ่งกิโล... แขนสั่นเหมือนเจ้าเข้า
[วิ่งลู่วิ่ง หอบ]
วิ่งได้สามนาที... เห็นภาพแฟนเก่าลอยมา
[วิ่งเร็วขึ้น ไฟลุก]
เลยวิ่งต่ออีกสิบนาที ด้วยความแค้น
[เช้าวันต่อมา ลุกจากเตียงไม่ไหว]
แต่เช้านี้... ลุกจากเตียงไม่ได้ ปวดทุกอณูของร่างกาย
[ยิ้มทั้งที่ปวด]
แต่แปลกนะ... ใจมันเบาขึ้นนิดนึง
จบวันที่เก้า มูฟออนติดลบสิบเปอร์เซ็นต์
วันที่สิบเริ่มแล้ว... ตอนหน้า กดอันฟอลโลว์เขา
```

## Day 10 — กดอันฟอลโลว์ (-10% → 0%)
เพิ่มใน style: _ตอนจะกดให้ลุ้นเหมือนกู้ระเบิด ตอนกดสำเร็จให้ดีใจสุดตัว_
```
[มือถือเครื่องใหม่ หน้าโปรไฟล์เขา]
วันที่สิบ... มือถือเครื่องใหม่ ภารกิจใหม่
วันนี้... จะกดอันฟอลโลว์เขา
[นิ้วจ่อปุ่ม เหงื่อแตก เสียงนาฬิกาติ๊กๆ]
ลุ้นยิ่งกว่ากู้ระเบิด...
ตัดสายสีแดง... หรือสายสีน้ำเงิน...
[กด! ปุ่มเปลี่ยนเป็น "ติดตาม"]
กดแล้ว! อันฟอลโลว์แล้ว!
[พลุ เพื่อนเฮ]
ไม่ต้องเห็นหน้าเขาในฟีดอีกต่อไป
[ตัวนับวิ่งขึ้นเป็น 0%]
จบวันที่สิบ มูฟออน ศูนย์เปอร์เซ็นต์ ไม่ติดลบแล้ว!
วันที่สิบเอ็ดเริ่มแล้ว... ตอนหน้า ลงสตอรี่ให้เขาเห็น
```
