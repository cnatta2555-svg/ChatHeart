# มูฟออน 30 วัน — สคริปต์ Day 26–30 (ตอนจบซีซั่น 1)

Style instructions พื้นฐาน (เสียง Leda):
> อ่านแบบสาววัยรุ่นเล่าเรื่องให้เพื่อนสนิทฟัง ตลกปนเศร้า ประชดตัวเองนิดๆ จังหวะเร็ว มีเว้นจังหวะก่อนมุก

---

## Day 26 — ทำไมรู้สึกเฉยๆ (65% → 80%)
เพิ่มใน style: _งงๆ แปลกใจตัวเอง ตอนท้ายยิ้มสบายใจ_
```
วันที่ยี่สิบหก... ตื่นมาแล้วรู้สึกแปลกๆ
ลองเปิดเพลงที่เคยร้องคู่กัน... เฉยๆ
ลองนึกถึงหน้าเขา... ก็เฉยๆ
เดินผ่านร้านหมูกระทะร้านเดิม... แค่รู้สึกหิว
เพื่อนถามว่า หายแล้วเหรอ
ไม่รู้สิ... แต่ทั้งวันไม่ได้นึกถึงเขาเลย จนถึงตอนนี้แหละ
จบวันที่ยี่สิบหก มูฟออน แปดสิบเปอร์เซ็นต์
วันที่ยี่สิบเจ็ดเริ่มแล้ว... ตอนหน้า เดตครั้งแรก
```

## Day 27 — เดตครั้งแรก (80% → 85%) — ปูซีซั่น 2
เพิ่มใน style: _ตื่นเต้น เขินๆ ตอนท้ายใจเต้นแบบสบายๆ_
```
วันที่ยี่สิบเจ็ด... หนุ่มฟิตเนสคนนั้น ชวนไปกินกาแฟ
ลองชุดไปสามชุด... สุดท้ายใส่ฮู้ดตัวเดิม
คุยกันสองชั่วโมง... ไม่มีพูดถึงแฟนเก่าเลยสักคำ
เขาหัวเราะกับมุกห่วยๆ ของฉันด้วย
ยังไม่รู้หรอกว่าจะไปต่อไหม... แต่ใจมันเต้นแบบสบายๆ
จบวันที่ยี่สิบเจ็ด มูฟออน แปดสิบห้าเปอร์เซ็นต์
วันที่ยี่สิบแปดเริ่มแล้ว... ตอนหน้า จดหมายถึงตัวเอง
```

## Day 28 — จดหมายถึงตัวเอง (85% → 90%)
เพิ่มใน style: _อ่อนโยน ซึ้ง ช้าลงกว่าปกติ เหมือนอ่านจดหมาย_
```
วันที่ยี่สิบแปด... เขียนจดหมายถึงตัวเองเมื่อสามสิบวันก่อน
ถึงฉัน... ที่นั่งส่องไอจีเขาตอนตีสอง
ไม่ต้องรีบหายนะ ร้องไห้ได้ กินมาม่าได้
ไม่ต้องเก่งทุกวัน... แค่ไม่ยอมแพ้ก็พอ
อีกไม่นาน เธอจะหัวเราะได้อีกครั้ง... ฉันสัญญา
จบวันที่ยี่สิบแปด มูฟออน เก้าสิบเปอร์เซ็นต์
วันที่ยี่สิบเก้าเริ่มแล้ว... ตอนหน้า กล่องใต้เตียง
```

## Day 29 — กล่องใต้เตียง (90% → 95%)
เพิ่มใน style: _สงบ มั่นใจ อบอุ่น_
```
วันที่ยี่สิบเก้า... ดึงกล่องที่ฝากไว้ใต้เตียงออกมา
ตุ๊กตาหมี... ตั๋วหนัง... เสื้อฮู้ดของเขา
คราวนี้มือไม่สั่นแล้ว
ตุ๊กตาหมีให้น้องข้างบ้าน เสื้อเอาไปบริจาค
ส่วนตั๋วหนัง... เก็บไว้เป็นความทรงจำดีๆ
ไม่ได้ทิ้งเพราะเกลียด... แต่เพราะไม่ต้องเก็บไว้อีกแล้ว
จบวันที่ยี่สิบเก้า มูฟออน เก้าสิบห้าเปอร์เซ็นต์
พรุ่งนี้... วันสุดท้าย
```

## Day 30 — มูฟออน 100% (ตอนจบ) — ปูซีซั่น 2
เพิ่มใน style: _ภูมิใจ ซึ้ง ขอบคุณคนดูจริงใจ ตอนท้ายตื่นเต้นกับซีซั่นใหม่_
```
วันที่สามสิบ... วันสุดท้ายแล้ว
สามสิบวันก่อน ฉันส่องไอจีเขาวันละสี่สิบเจ็ดครั้ง
วันนี้... จำไม่ได้ด้วยซ้ำว่าเขาลงรูปอะไรล่าสุด
ผมทรงเห็ดยาวขึ้นแล้ว... ใจก็โตขึ้นด้วย
ขอบคุณทุกคนที่ดูมาด้วยกันทั้งสามสิบวัน
ทุกคอมเมนต์ ทำให้ฉันไม่รู้สึกว่าเดินคนเดียว
มูฟออน... หนึ่งร้อยเปอร์เซ็นต์!
แล้วมือถือก็เด้ง... หนุ่มฟิตเนสทักมา
ภารกิจใหม่... หาแฟนใหม่ในสามสิบวัน ซีซั่นสอง เร็วๆ นี้!
```
