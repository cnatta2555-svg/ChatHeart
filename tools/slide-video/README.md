# Slide Video: ทำคลิปสไลด์ที่ขยับตรงกับเสียงพากย์

เครื่องมือนี้เอาไฟล์เสียงพากย์ (เช่น จาก ElevenLabs) กับสไลด์ที่เขียนเป็น HTML มาทำเป็นคลิปแนวตั้ง 1080×1920 สำหรับ TikTok, Reels และ Shorts
ข้อความ ตัวเลข และกราฟจะ**โผล่ตอนที่เสียงพูดถึงพอดี** โดยไม่ต้องจดเวลาเอง

## ทำงานอย่างไร

1. **ถอดเสียง:** `transcribe.py` ใช้ Whisper (faster-whisper) ถอดเสียงพร้อมเวลาของแต่ละคำ ผลลัพธ์เก็บเป็นไฟล์ `<ชื่อไฟล์เสียง>.words.json` ไว้ข้างไฟล์เสียง รอบต่อไปไม่ต้องถอดซ้ำ
2. **จับเวลา:** `align.py` เอาคำที่เขียนไว้ใน `data-cue` ของสไลด์ไปหาในเสียง จับคู่แบบยอมให้สะกดเพี้ยนได้ แล้วได้เวลาเป็นวินาที
3. **เรนเดอร์:** `make_video.js` เปิดสไลด์ใน Chromium (Playwright) ถ่ายทีละเฟรมที่ 30 fps แล้วให้ ffmpeg รวมกับเสียงเป็น MP4

## ติดตั้ง (ครั้งแรก)

```bash
pip install faster-whisper      # ต้องมี ffmpeg และ node + playwright อยู่แล้ว
```

ครั้งแรกที่ถอดเสียงจะดาวน์โหลดโมเดล `large-v3-turbo` (ประมาณ 1.6 GB) จาก Hugging Face
โมเดลนี้ถอดเสียง 2 นาทีบน CPU 4 คอร์ในเวลาประมาณ 1 นาที

## ใช้งาน

```bash
# 1) พรีวิวภาพที่เวลาต่างๆ ก่อน (เร็ว) และดูตารางเวลาที่จับได้
node make_video.js examples/insure-tax-gold.html voice.mp3 out/clip.mp4 --preview 5,30,60,90

# 2) เรนเดอร์คลิปเต็ม (คลิป 2 นาทีใช้เวลาประมาณ 4–5 นาที)
node make_video.js examples/insure-tax-gold.html voice.mp3 out/clip.mp4
```

ตัวเลือกเพิ่ม: `--fps 30` และ `--model large-v3-turbo` (เลือก `medium` หรือ `small` ได้ เร็วกว่าแต่แม่นน้อยกว่า)

ตอนรัน โปรแกรมจะพิมพ์ตารางเวลาที่จับได้ บรรทัดที่มี ⚠ (score ต่ำกว่า 0.6) แปลว่าหาคำนั้นในเสียงไม่ค่อยเจอ ให้เปลี่ยนคำใน `data-cue` เป็นคำอื่นในประโยคเดียวกัน

## ทำคลิปใหม่

ก๊อปไฟล์ `examples/insure-tax-gold.html` แล้วแก้แค่ส่วน `<section class="slide">` ส่วน engine ด้านล่างไม่ต้องแตะ

| ใส่ที่ element | ความหมาย |
|---|---|
| `<section class="slide" data-cue="คำแรกของหน้า">` | เปลี่ยนเป็นหน้านี้ตอนเสียงพูดคำนี้ |
| `class="r" data-cue="คำที่พูด"` | ข้อความโผล่ตอนเสียงพูดคำนี้ |
| `class="r" data-d="0.3"` | โผล่หลังเริ่มหน้า 0.3 วินาที (ใช้กับหัวข้อที่เสียงไม่ได้พูด) |
| `data-after="คำ" data-d="2"` | โผล่ 2 วินาทีหลังเสียงพูดคำนี้ |
| `data-pop="1"` / `data-x="1"` | เด้งเข้า / เลื่อนเข้าจากซ้าย (ถ้าไม่ใส่จะเลื่อนขึ้น) |
| `data-count="20450"` | ตัวเลขนับขึ้น ใช้ร่วมกับ `data-from` (ค่าเริ่ม), `data-ccue` (เริ่มนับตอนพูดคำนี้) และ `data-cl` (ใช้เวลานับกี่วินาที) |
| `data-w="51"` | กราฟแท่งยืดไปที่ 51% ใช้ร่วมกับ `data-from` และ `data-ccue` ได้ |

**เคล็ดลับ:**
- **ใช้คำ ไม่ใช้ตัวเลข** เป็น cue เพราะ Whisper เขียนตัวเลขไทยเพี้ยนบ่อย เช่น ได้ยิน "หนึ่งแสน" แต่เขียนว่า 1,000
- **เรียง cue ตามลำดับที่พูด** เพราะโปรแกรมหาคำในเสียงจากต้นไปท้าย
- **คำที่พูดซ้ำหลายครั้ง** (เช่น "เงินเดือน") จะจับคู่กับครั้งถัดไปหลังจาก cue ก่อนหน้า
- **เปลี่ยนธีมสี** ได้ที่ตัวแปร `:root` ใน `<style>` ส่วนพื้นหลังและประกายทองแก้ได้ที่ฟังก์ชัน `drawBg()`

## ไฟล์

- `make_video.js`: ตัวหลัก
- `transcribe.py`: ถอดเสียงพร้อมเวลาของแต่ละคำ
- `align.py`: จับคู่ cue กับเวลา
- `examples/insure-tax-gold.html`: ตัวอย่างธีมทองน้ำตาล 8 หน้า (ประกันลดหย่อนภาษี)
- `fonts/`: ฟอนต์ Prompt (Google Fonts, SIL Open Font License)

## ธีม (กติกาของเจ้าของช่อง)

**ทุกคลิปต้องเปลี่ยนธีมใหม่ ไม่ซ้ำกับคลิปก่อนหน้า** แต่ยังเน้นสี**ทองกับน้ำตาล**

ธีมเก็บไว้ที่ `themes/*.css` ใส่เป็น `<style>` หลังสไตล์หลัก เพื่อเขียนทับตัวแปรสี (`--cream` ตัวหนังสือ, `--gold*`, `--bgA/B/C` พื้นหลัง, `--dust` สีประกาย)

| ธีม | ลักษณะ | ใช้แล้วในคลิป |
|---|---|---|
| `dark-gold` (ค่าเริ่มต้น) | พื้นน้ำตาลเข้ม ประกายทอง | ลดหย่อนภาษี, 5 คำถาม, อุบัติเหตุ vs สุขภาพ |
| `latte` | พื้นครีมสว่าง ตัวหนังสือน้ำตาลเข้ม ป้ายน้ำตาล | เงินเดือน 2 หมื่น |

คลิปถัดไปให้สร้างธีมใหม่ เช่น ทองบนพื้นช็อกโกแลตลายเส้น, ไม้/กระดาษคราฟต์, หินอ่อนครีมขอบทอง, ทองแดงโรสโกลด์ แล้วเพิ่มลงตารางนี้
